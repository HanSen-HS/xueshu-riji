配置 Google Drive 授权

需要创建 Google Cloud 凭据才能使用 Drive 集成功能。按以下步骤操作：

1
访问 Google Cloud Console

打开 console.cloud.google.com，新建或选择一个项目

2
启用 API

在「API 和服务」→「库」中搜索并启用：
Google Drive API 和 Google People API

3
创建 OAuth 凭据

「API 和服务」→「凭据」→「创建凭据」→「OAuth 客户端 ID」
应用类型选 Web 应用
授权重定向 URI 填写：http://localhost:5001/oauth2callback

4
下载并放置凭据文件

下载 JSON 文件，重命名为 client_secrets.json
放到应用目录：{{ app_dir }}

5
重启应用

重新运行 python3 app.py，配置即生效
